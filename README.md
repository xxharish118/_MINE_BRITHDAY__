# PAVITHARA — A World Made With Love ❤️

## Run it
```bash
npm install
npm run dev      # open the printed local URL
npm run build    # production build in /dist (upload to Netlify / Vercel / GitHub Pages)
```

## Customise (everything is in `src/config.js`)
- **Photos:** files are in `public/images/` (photo1.jpg … photo6.jpg are your uploads). Replace a file keeping its name, or edit the list in `config.js`. Add more by adding entries (missing photos show a placeholder).
- **Captions, letter, cards, secret message:** same file.
- **Music:** the birthday song is `public/audio/music.m4a`. It starts when she taps "Open your surprise" and loops; the player (bottom-right) pauses/plays it. Replace the file to change the song.
